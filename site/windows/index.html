Install the WinUSB driver with Zadig

Windows needs the WinUSB driver for the oscilloscope. You install it once with Zadig.

  1. Connect the oscilloscope.
  2. In Zadig, choose Options → List All Devices.
  3. Select the device with ID 04B4 6022, choose WinUSB and click Replace Driver.
  4. Start the app. It loads the firmware, and the device reconnects with ID 04B5 6022.
  5. In Zadig, select the device 04B5 6022 and install WinUSB again.

The 6022BE keeps no firmware. When the app connects, it loads the firmware into the device RAM, and the device then reconnects with a new USB ID, 04B5 6022. Windows sees a new device, so WinUSB is installed twice: once for 04B4 6022 and once for 04B5 6022.

Restore the original Hantek driver

The original Hantek software stops working while WinUSB is installed. To restore it, open Device Manager and reinstall the Hantek driver for the oscilloscope. Then the original Hantek software works again.

Troubleshooting and FAQ

The computer does not find the oscilloscope. What do I check?

Check the USB cable and the port. Then open Zadig and choose Options → List All Devices. Before the firmware load, the device is listed with ID 04B4 6022.

The second Zadig step was skipped. What do I do?

After the app loads the firmware, the device reconnects with ID 04B5 6022 and has no WinUSB driver yet. Open Zadig, select the device 04B5 6022 and install WinUSB again.

Does it work on Windows 10?

Windows 10 and Windows 11 are both listed as supported systems, and the installation steps are the same. Test reports for either version are welcome.

Can I use it together with OpenHantek6022?

OpenHantek6022 also uses WinUSB for the 6022BE, so both projects rely on the same Zadig driver setup. This project shares no code with OpenHantek.

What works on Windows

The desktop app has been tested with the device on Windows. The command-line tool (h6022) and the MCP server have not been tried on Windows yet.
